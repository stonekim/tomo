# ADR-0002: 00 shared foundation and contract v1

Accepted 2026-11-12. Supersedes ADR-0001's temporary no-stack/no-remote decision; deployment location is configurable, never a host-specific lab path.

Python >=3.11, FastAPI/Pydantic HTTP boundary, JSON Schema 2020-12, SQLite WAL with explicit transactions, standard-library scrypt and hashed opaque bearer sessions. One service process, one persistent local database, no browser secrets. Static frontend modules can be added independently; no frontend framework imposed by 00. SQLite is appropriate for this single-node MVP; multi-node writes require a future migration/ADR.

Contract v1 lives in `src/tomo/contracts/v1.json`; generated OpenAPI is checked in at `docs/contracts/openapi.json`. `/api/v1` is the stable prefix. Breaking changes require v2, new migration and consumer agreement. Unknown fields are rejected. All IDs are opaque strings. UTC RFC3339 timestamps, integer revisions. Errors use `{error:{code,message}}`; 401 unauthenticated, 404 absent or foreign resource (do not leak existence), 409 revision/idempotency conflict, 422 malformed/invalid operation, 503 unavailable domain/provider. Retry only timeouts/transport/429/5xx, bounded, with each attempt audited.

00 owns `src/tomo/platform`, `src/tomo/contracts`, `tests/platform`, `docs/contracts`, shared packaging/config and this ADR. 01 owns `src/tomo/game`, `web/src/game`, `tests/game`; 02 owns `src/tomo/plans`, `web/src/plans`, `tests/plans`; 03 owns `web/src/shell`, `web/src/shared`, `tests/shell`; 04 owns `integration`, `deploy`, `tests/system`. No simultaneous writes to shared files: propose contract changes to 00. Domain route factories are composed through `create_app(..., domain_routers=...)`; rule validators are registered via `RuleRegistry`, keyed by domain. There are no implemented business modules in 00.

Save domain is immutable (`game` or `plan`); the database checks ownership on every read/write in the same transaction. Plan saves cannot acquire game events and game saves cannot acquire plan versions. Game branch history is an immutable prefix copied at fork, preserving event IDs; descendants append independently. Compare-and-swap revision and owner-scoped idempotency keys make retries safe. A domain rule validator must approve every state transition before commit; missing validators fail closed. Rules receive detached input and may not perform external side effects; transaction rollback prevents invalid writes. Model calls are outside storage transactions.

Plan judgment versions are append-only snapshots with prior revision linkage. Outcomes reference a particular version; 02 supplies due-date/assessment rules. No game memories are automatically supplied to plans. Domain logic must explicitly provide authorized context. Version storage itself does not imply business validation or forecast accuracy.

Model adapter is server-only, provider HTTP Chat Completions compatible, fixed HTTPS endpoint, no user-selected URL/tools. API key only from environment. Prompt/output and credentials are never persisted in audit; usage input/output/cache counters are independent nullable integers. Cost and currency are null unless actually supplied by a provider; no inferred prices. Cache tokens are provider-reported cached input tokens, not subtracted from input. Retries are at most three attempts. A durable pending audit precedes each attempt so crashes retain unknown usage. Mock is a separate explicit adapter and cannot be mistaken for a real call.
